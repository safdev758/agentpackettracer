# Engineering roadmap

Current native support is Linux with the tested versions in [validation](../VALIDATION.md). These issues describe future work and concrete acceptance criteria, not completed capabilities.

| Priority | Deliverable | Tracked issue |
| --- | --- | --- |
| 1 | Installation preflight, configurable executable paths, clean-desktop onboarding | [#2](https://github.com/safdev758/agentpackettracer/issues/2) |
| 2 | Exact topology requirements and reconciliation after unknown execution | [#3](https://github.com/safdev758/agentpackettracer/issues/3) |
| 3 | Backend byte limits and redacted per-stage timing | [#4](https://github.com/safdev758/agentpackettracer/issues/4) |
| 4 | Codex version compatibility and explicit account onboarding | [#5](https://github.com/safdev758/agentpackettracer/issues/5) |
| 5 | Windows platform adapter and real native acceptance | [#1](https://github.com/safdev758/agentpackettracer/issues/1) |

Keep correctness, cancellation and private provisioning ahead of broader autonomous claims. The immediate follow-up-context bug is fixed by bounded session memory and six regressions; durable memory and detection of manual lab replacement require further design. See [the engineering guide](ENGINEERING_GUIDE.md) for skills, review rules and a learning sequence.
